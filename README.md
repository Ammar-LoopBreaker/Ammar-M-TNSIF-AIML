#  6. Supervised Learning

This section contains assignments and implementations based on **Supervised Machine Learning**.

In supervised learning, a model learns from a **labelled dataset**, where the input features and expected output are already known.

###  Linear Regression

Used to predict **continuous numerical values**.

**Example:**

```text
Years of Experience → Salary
```

The model learns the relationship between experience and salary to predict salary values for new inputs.

---

###  Logistic Regression

Used mainly for **binary classification problems**.

**Example:**

```text
Age + Income → Product Purchase
```

The model predicts one of two possible classes, such as:

```text
0 → No
1 → Yes
```

---

###  Decision Tree

A Decision Tree makes predictions by learning a sequence of **decision rules** from the training data.

**Example:**

```text
Age + Income → Product Purchase
```

The model creates decision-based branches to classify the input.

---

###  Random Forest

Random Forest combines multiple Decision Trees to improve prediction performance and reduce dependence on a single tree.

**Example:**

```text
Age + Tenure + Monthly Bill → Customer Churn
```

It combines the predictions from multiple trees to produce the final result.

---

#  7. Model Evaluation

Understanding model performance is an important part of the machine learning workflow.

The training exercises cover commonly used classification metrics such as:

| Metric           | Purpose                                                            |
| ---------------- | ------------------------------------------------------------------ |
|  **Accuracy**  | Measures the overall percentage of correct predictions             |
|  **Precision** | Measures how many predicted positive results are actually positive |
|  **Recall**    | Measures how many actual positive cases were correctly identified  |
|  **F1-Score**  | Provides a balance between Precision and Recall                    |

These metrics help in understanding how effectively a machine learning model performs on unseen/test data.
